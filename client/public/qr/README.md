# QR codes

Print `product-001-qr.png` on packaging / flyer.

**User flow (mở app → mở link):**
1. Open the phone **Camera app**
2. Scan this QR → browser opens the AR page
3. Tap **Cho phép Camera** in the page
4. Point at the **image target** (`../targets/product-001.png`), not the QR

Guide page: open `/qr/` on the deployed site.
